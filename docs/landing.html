What you can't do in Ollama or LM Studio

Thinking modes

Shipped

A profile bundles model + sampling + system prompt + workflow into one named, saved, one-click preset. Editable as TOML. Ollama exposes these only as per-request params; LM Studio has no explicit profiles.

Fast Think

Shipped

A profile that runs the same model greedily with a speculative drafter — fewer waits, identical output — on the bundled Apple-Silicon engine. Just pick the profile.

Reasoning, separated

Shipped

Models that emit a <think> scratchpad get a collapsible Thinking section, so the reasoning never mixes into — or gets copied with — the answer.

Tree-of-Thought

Preview

The chat-apc engine can run a bounded Tree-of-Thought search via the local API (POST /v1/inferlet). Honest status: an API capability today, not yet a one-click profile.

Everything runs on your Mac. No accounts, no cloud, no telemetry.
