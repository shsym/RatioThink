What you can't do in Ollama or LM Studio

One real difference: profiles — named thinking modes you switch in one click. Everything below is a profile.

Thinking modes

Shipped

A profile is a named, one-click preset — model + sampling + system prompt + workflow — saved to disk and editable as TOML. Ollama exposes these only as per-request params; LM Studio has no explicit profiles.

Tree of Thought

Shipped

A profile that turns one question into a scored search tree: the engine branches, scores each branch 1–10, and keeps the best beam — shown live in a foldable tree, then the chosen answer.

Fast Think

Shipped

A profile that runs the same model greedily with a speculative drafter — fewer waits, identical output — on the bundled Apple-Silicon engine. Just pick it.

Everything runs on your Mac. No accounts, no cloud, no telemetry.
